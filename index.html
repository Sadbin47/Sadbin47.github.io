About

nvimabout.md

I’m a Computer Science & Engineering student at American International University-Bangladesh, working where deep learning meets healthcare.

My manuscripts look at making medical-image classifiers lighter and easier to explain, checking whether they stay reliable when the data shifts, and sharing health records in a way that holds up against post-quantum threats. Across all of it, I care about evaluation that someone else can reproduce.

Outside the lab I live in the terminal. I’ve written an interactive Arch Linux installer, a self-hosted seedbox manager and my own Hyprland setup — all in shell. Shipping tools that partition real disks taught me to respect safe defaults, clear error messages and a confirmation before anything destructive. Good research needs the same discipline.

Featured project

ResQRoute

An offline-first Android app that routes people to flood shelters when mobile networks fail.

  • No internet, by design. The road graph and shelter list ship inside the app — it never even requests the INTERNET permission.
  • Flood-aware A*. Blocked roads drop out of the search; waterlogged ones cost more with depth, recency and how many reports agree.
  • Phone-to-phone sync. Road reports spread over Bluetooth and Wi-Fi with Google Nearby Connections — no server, no SIM.

The s4d toolkit

Bare metal to a working desktop or server, written entirely in shell. Each tool runs on its own; s4dutil puts them behind a single menu.

  2. s4darc installs Arch

bashs4darc.sh 5 GitHub stars

s4darc

An interactive Arch Linux installer. No compiling, no dependencies — it runs straight from the official live ISO.

  • Guided partitioning, with a confirmation before anything destructive
  • UEFI & BIOS · GRUB or systemd-boot · your choice of kernel
  • ext4, btrfs or xfs · locale, users and sudo configured for you
bash <(curl -fsSL https://raw.githubusercontent.com/Sadbin47/s4darc/main/s4darc.sh)

bashs4dbox 2 GitHub stars

s4dbox

A seedbox manager with a Bash TUI: install, monitor, tune and secure a media and torrent server from one menu.

  • qBittorrent, rTorrent, Jellyfin, Plex, Sonarr, Nextcloud and more
  • Hardening built in: SSH, firewall and Fail2ban
  • Tailscale, WireGuard, OpenVPN · optional Nginx reverse proxy
curl -fsSL https://raw.githubusercontent.com/Sadbin47/s4dbox/main/install.sh | sudo bash

bashs4d_hyprland 2 GitHub stars

s4d_hyprland

A minimal, bloat-free Hyprland setup for Arch, with a gradient-styled TUI installer and live progress.

  • GPU auto-detection: NVIDIA, AMD, Intel and hybrid laptops
  • Pick SDDM or Ly, Waybar or DankMaterialShell, Hyprlock ± Wlogout
  • Catppuccin Mocha by default — the palette this site is built on
